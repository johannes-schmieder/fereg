## Prior campaign and scientific limits

In the main baseline, native OLS changed from 0.920770 seconds in beta.11 to
0.819174 seconds in beta.15 (11.0% less time), while PPML changed from
4.147969 to 5.720168 seconds (37.9% more time). These are separate-host
descriptive comparisons, not isolated software effects. Main synthetic task 5
ran on Gold 6132; the other five tasks and corrected No FE ran on E5-2680 v4.
Both Veneto models ran on separate Gold 6132 hosts. The SCC rerun does not isolate the parallel numeric accessor's contribution.
A later [controlled Mac experiment](macos-20261103-accessor-ablation-50rhs.md)
compares serial and parallel readers on the same 20-million-row dataset with
50 RHS variables and 20 workers: median loading time falls from 4.597 to 0.958
seconds, and whole-command time from 10.656 to 6.981 seconds. That result
applies to the specified Mac experiment, not to the SCC speed changes.

The reghdfe and ppmlhdfe command limits were raised from 600 to 3,600 seconds;
other arms retained 600 seconds. Veneto uses only the largest connected set:
OLS models log daily wages and PPML models the same wages in levels. The new
PPML panel is therefore not a speed comparison with the old Panel B.

Veneto OLS has all 114 planned positions. Veneto PPML has all 84: 78 successful
executions, two command timeouts and four skipped positions. Both native
smoke and production gates pass. Default fixest fails PPML covariance checks;
strict fixest passes the independent smoke but times out in production at
one and two cores. Default Julia fails Veneto OLS coefficient/objective checks;
strict Julia agrees up to the recorded degrees-of-freedom convention. Known
saved-prediction comparator discrepancies, main-campaign failures and timing
variation remain in the frozen evidence rather than being retried or hidden.

The Julia No FE repair (`c8a7d7d3`) changed only the post-fit empty count-vector
type. Its predeclared replacement reran the complete OLS No FE cell, with all
arms on one host; original failed captures and original observations remain
retained as superseded evidence. Granite's original smoke `8409510` failed
before any fit because the host monitor did not admit `omp32`; production
`8409511` rejected that failed prerequisite. Source `32024c10` added admission
with the same isolation checks, and all 454 harness tests passed in the repaired
setup. Original failures are retained under `granite-rapids/superseded-setup-omp32`
at the SCC root. Neither repair resampled measured fit timings.
