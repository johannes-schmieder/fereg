# Frozen benchmark expectations

Numerical and identity expectations are frozen by the OLS-v1 reference and
independent-oracle receipts. Candidate performance evidence is accepted only
after scientific parity and under the 0.9.0 gates in ADR-0007. Licensed baseline
captures must store sample hashes, coefficient/VCE matrices, iteration counts,
deletion counts, wall time, peak RSS, Stata metadata, and exact plugin hashes
here. Never use a speed number without the corresponding scientific outputs.
