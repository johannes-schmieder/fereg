# Frozen cycle routing: two fresh Mac validation blocks

The captured cy2 candidate passes both frozen, independent five-pair blocks
on seeds 202609211 and 202609212. The candidate, comparison artifact, guard,
controllers, scientific auditors and thresholds were frozen before either
seed was measured. No guard or threshold was tuned from these results.

All 1,920 planned application calls complete, with no detected timing overlap.
Each block contains 46 current/candidate/reference screen cells and 28
automatic/explicit LSMR route cells. Ordinary fixest is omitted from the two
frequency-weight screen cells because its weighted inference does not supply
Stata frequency-weight semantics.

The automatic-route comparison uses the fastest valid competing family from
the preceding solver investigation, explicit LSMR. It includes complete
command setup, graph detection, inference and requested output recovery. It
does not repeat all previously rejected solver families. The selected rule
remains the exact structural and memory predicate in ADR 0093; this is not a
general switch from Schur-CG to LSMR.

Both blocks pass independent native inference checks for all 46 cells and
all 230 paired native routing checks. Selected cases use certified LSMR;
excluded cases retain exact scientific exports and solver reports apart from
timings. Both native variants pass all 320 saved-output run audits per block.
The separate route comparisons pass all 280 independent scientific checks
per block, including their requested outputs. The joined adjudication accepts
every predeclared local timing and native-science criterion.

Default fixest passes the independent inference audit in ten comparable
cells per block and disagrees in 34. These discrepancies remain recorded
failures, not accepted scientific parity. The timing wins above describe
the measured default-reference commands. They do not establish that all
reference results achieve the native accuracy requirements.

`evidence.zip` preserves the application and controller evidence, with large
output arrays kept locally under recorded hashes. `checks.zip` preserves the
freeze, complete audit results and adjudication. `sources.zip` reconstructs
both native source trees from their recorded commits and captured overlays,
and includes the controllers and independent scientific code. The earlier
training and constrained-memory evidence is linked by the freeze and retained
in the [memory checkpoint](../cycle-routing-memory-local-2026-09-21/README.md).
Raw licensed logs and binaries are excluded. Run `verify.py` to verify the
portable evidence and source reconstruction; detailed timing rows are in
[timings.md](timings.md).

The first verifier attempt used the wrong field name for the output-auditor
hash. `verifier-repair.zip` and its hash record preserve that verifier, the
failed log and the one-field correction. The corrected receipt is
`integrity2.json`; no application, scientific audit or timing result changed.

This is successful Mac development validation. Production routing remains
unchanged: the planned Linux confirmation is still blocked on SSH renewal.
This archive does not adopt the route, install a package, authorize a push or
release, or close the broader optimization milestone. The higher memory cost
and constrained-memory failures in the preceding checkpoint remain applicable.
