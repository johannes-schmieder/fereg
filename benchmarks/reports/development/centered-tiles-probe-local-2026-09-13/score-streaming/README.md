# P5 centered scores: unadopted component prototype

This stage extends the [frame/core-certificate prototype](../frame-certificate/README.md)
against accepted `436fe2a`. The [receipt](receipt.json) binds 182 inputs,
six changed since that stage, the complete patch and twelve sanitized logs.
There is no production route or plugin build, and no speed or memory gain is
claimed. Earlier receipts remain attached to their exact source snapshots.

The score storage borrows centered numeric/virtual-intercept columns and feeds
the existing robust and qualified cluster reductions. An independent compensated
row-wise Gram certificate checks the existing bread. The adapter validates
response, weights, numeric columns and FE topology by borrowed identity before
inference reservations. It releases the displaced matrix cache, retaining its
exact means when its generated-column identities match. Otherwise it uses the
existing rebuilt-score mean policy. Production changes only extract shared
coordinate/mean helpers and score-factory seams; their complete-command cost
still requires measurement.

**These tests consume matrix-produced coefficient fits.** The preceding stage
tests centered finite/core finalization separately. Neither proves a complete
centered estimator or resolves packed inference's distinct finite-reference
norm policy.

## Validation

All 105 distinct tests pass on the final source: 23 centered tests (five new),
64 existing prepared-fit tests, nine robust and nine clustered tests. Non-test
core checking passes. The receipt distinguishes five final-source logs from
seven intermediate logs; counts are verified against named tests and terminal
summaries.

The five new tests include 28 full covariance comparisons (20 robust, eight
clustered), covering unit/AW/FW/PW, both packed-cache requests, literal frequency
expansion, normalized intercept/no intercept, rank zero, exact rank deficiency,
gapped FE-collinear slots, K65 and parallel reductions at N32777. Independent
rational weighted HC1 and original-row inclusion–exclusion cluster calculations
agree under the unchanged covariance tolerance. Cluster missingness occurs
before singleton deletion: the frequency fixture retains 256 rows and the
analytic fixture 255, reflecting their existing multiplicity rules. Full rank,
DoF, weight, FE/cluster/subset and PSD structures match the matrix consumers.

Seven injected inference-reservation failures, one-byte-under/exact capacity,
overcapacity, invalid axes and equal-valued foreign response/weight/column/FE
bindings fail as intended. The tiny successful certificate requires 64 new
reserved payload bytes. That component accounting excludes the bound source,
existing fit and retained means; it is not full estimator admission or a native
peak measurement.

The first clustered test failed because its one-way fixture left an unused
second cluster source. The fixture was corrected to remove that source. A new
boundary test initially called a nonexistent `PreparedWeights.values()` method;
it was corrected to use the actual frame. Both attempts are retained. No
scientific tolerance, sample policy or production error rule changed.
