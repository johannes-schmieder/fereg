# Exact-cycle automatic LSMR experiment

The captured cy1 source evaluates ADR 0093's exact connected-cycle predicate
before public fast two-intercept automatic OLS. Production routing is unchanged.
It reuses automatic LSMR's existing tolerance, memory admission, fallback and
fresh certificates. It charges successful and rejected probe setup and peak
workspace outside early Schur returns. Explicit/shared/higher-dimensional,
low-memory and excluded graph routes retain their existing policy.

The focused fixture checks row order, group labels, effect swaps, connectivity,
paths, chords, unequal group sizes, weight dispersion and budget rejection.
The captured plugin passes the actual ABI fixture.

The training screen completes 46 cells and 276 successful calls with clean
isolation. All 92 independent native inference checks, 276 exact within-arm
repeat checks and 96 candidate output audits pass. The route audit passes
138 pairs: 84 selected pairs use automatic LSMR without a failed solver or
Schur pilot; 54 excluded pairs retain exact finite exports, samples, status,
FE metadata, certificates, saved vectors and solver fields other than times.

All 28 targeted cycle cells improve: paired runtime ratios range from 0.5067
to 0.7500. All 18 excluded/explicit controls stay within 1.05, with worst
1.0465. These are three-pair training measurements, not fresh validation or
final acceptance. Both unused routing seeds and Linux confirmation remain
required before production adoption. The control margin is narrow.

Tracked peaks increase in every selected pair, by 18,571,188 to 482,354,402
bytes. Among all 138 pairs, 44 peaks match; excluded-pair differences range
from -3,143,088 to +8,863,744 bytes. There is no memory-neutrality claim.
Whole-fit constrained admission remains to be exercised. The tiny borrowed
FE descriptor's joint accounting also needs review before adoption; this
experiment does not establish a complete allocation proof.
