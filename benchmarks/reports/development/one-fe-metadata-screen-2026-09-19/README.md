# Public coefficient-name shortcut: rejected

A guarded shortcut used bare posted coefficient names directly instead of
walking the intended-name adapter. Ten metadata cases preserved return codes,
public names, coefficient/covariance names and scientific matrices; unsupported
commands remained unsupported. The initial audit incorrectly assumed all
commands would succeed and was repaired before the accepted check.

Three rotated primary blocks provide 18 accepted calls with unchanged native
scientific outputs. Narrow medians are 205/205 ms for baseline/candidate; wide
medians are 492/486 ms, without enough repeatable benefit to retain this branch.
The prototype was removed. No dedicated licensed fixture set or protected
control campaign was run for this rejected shortcut.

The candidate reused the committed statistics plugin, with only the public
ado dispatcher changed. Source identities, numerical measurements, comparison
receipts and the rejected patch are retained here. This is local development
evidence, not qualification or an optimization adoption claim.
