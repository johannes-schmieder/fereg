# Broad outcome-scan overlap: rejected scope

The prototype runs the unchanged independent IID outcome mean/TSS scan
alongside fitting on the existing native team. It borrows the same prepared
outcome, allocates no data buffer, and defers any error until the original
fit, DoF and weight checks have succeeded. The independent residual scan and
all arithmetic remain unchanged.

Five primary pairs in `../one-fe-sample-ownership-2026-09-19/` gave
samplemean/outcomefit medians of 183/177 ms for K=10 and 444/445 ms for K=50.
This archive adds 66 accepted control calls with bit-identical native science.
The 1,000-group, K=50, four-thread case has medians 636/673 ms, a 5.82%
slowdown. The eleven-control geometric mean ratio is 0.99689. This first
regression screen rejects the broad scope; it is not a confirmed five-pair
regression claim. The broad artifact is not adopted.

The next candidate restricts overlap to at most 16 generated model columns
and at least eight workers. That narrower source requires its own evidence.
The broad scope's three licensed fixtures pass. Its native tests preserve
coefficients, covariance, residuals, certificates and deferred error ordering.
The first full-result assertion also compared elapsed-time fields and failed;
the corrected check excludes those timing fields only. Raw logs and source
snapshots remain in the ignored work directory. This is local development
evidence, not qualification.
