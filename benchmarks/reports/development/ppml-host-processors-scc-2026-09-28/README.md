# Scoped PPML host processors: rejected public-command candidate

This bounded development experiment rejects transient host processor switching around the native PPML call. It retains the independently useful hidden native Break handshake correction. Neither the diagnostic profile nor rejected candidate is production speed evidence.

## Identities and validation

Baseline is accepted snapshot `5c0d4685…`, Linux plugin `94925723…`. Initial wrapper snapshot `0b3d1b61…` reused that plugin; its Linux validation job **7763612** passed all five licensed fixtures and 17 static tests but failed genuine native Break. It published its file handshake before `SF_display` returned. Ctrl-C could therefore produce an SPI display error instead of the required interruption result. Host restoration passed. This failed job remains failed; no headline timing used it.

Repaired measured package snapshot **`d2120024…`** binds 213 inputs in [candidate02-source.json](candidate02-source.json). Linux plugin **`d007491a…`**, Mac universal **`a7ad0493…`**. The only native change orders the hidden Break display before its controller handshake; normal numerical code is unchanged. Its existing native test now asserts that the handshake is absent during display.

Both platforms pass two focused native Break tests, 17 static transaction tests, four licensed oracle/control fixtures and genuine PTY Ctrl-C. Linux **7763618** also passes `scc-dev-ppml`, including build, ABI/panic checks and PPML smoke. Independent fixtures cover weighted Poisson/Hessian/sandwich, frequency/probability weights, robust/cluster inference, multipartition slopes and OLS. The host fixture covers requested 1/4/0, fast/low, prior populated/null estimates, panic, allocation failure, post-plugin failure and saved FE/mean reconstruction. Mac build first failed before compilation because cargo was absent from PATH; the explicit installed toolchain succeeded.

## Full public-command screen

Job **7763641**, isolated 28-core E5-2680v4, completes 60 applications and all 20 native plus 20 stock scientific pairs. Accounting:191 s, 1.972 GiB maximum virtual memory, zero scheduler/application errors. Two alternating baseline/candidate/stock rotations use known diagnostic seed 2026092817. No compilation, profiling, archiving or competing fit overlaps timing. Every native coefficient/covariance export is byte-identical. Iteration counts and modeled memory agree; tracked peaks differ only for existing three-FE workspace overlap, in both directions.

Public PPML uses robust inference; OLS uses IID. No optional observation outputs are requested in headlines. Pinned unmodified fixest 0.14.2 uses ordinary defaults except the slope control (`glm.tol=1e-10`, `fixef.tol=1e-11`). Sample/rank/DoF, numerical envelopes and failure treatment are unchanged. Native requests match stock; the candidate temporarily changes the Stata host setting only, including both setting calls in the public command clock.

## What the follow-up establishes

[Diagnostic 7763667](boundary06/README.md) completes 96 fits on the same candidate artifact after headline timing ends. Whole-public scoping nearly matches persistent host1, whereas native-only scoping leaves substantial Stata CPU work. One-FE diagnostic median falls 213→134.5 ms; two-FE 274.5→185.5 ms. Partial Stata self shares fall 67.39→8.60% and 62.42→4.12%. Every configuration produces byte-identical coefficients and covariance. This narrows the next candidate to the entire public-command boundary; it is not a production speed claim, and does not authorize changing the user's persistent environment.

## Retained checkpoint and remaining work

The rejected ado wrapper is removed. [Retained snapshot 7a245969…](retained-source.json) keeps only the native Break handshake correction and stronger host/native boundary fixtures. Linux plugin d007491a and Mac a7ad0493 are unchanged from candidate validation because the rollback changes ado only. The retained public ado matches the previous accepted source exactly. The universal 1.20 stock ceiling, 0.90 aspiration and monotonic scaling goal remain unmet. No fresh confirmation or direct scaling block was run. The next implementation should cover public parsing and temporary-output preparation while restoring caller state on every exit, preserving quiet/noisy behavior and the existing publication transaction. Then use uncontended baseline/candidate/stock rotations and fresh direct scaling. Preserve the existing categorical/slope/low/wide/large controls. Old weak-SE discrepancies, large timeouts, other comparator failures, static allocation drift and constrained-fit/nonretaining-CG issues remain unresolved.
