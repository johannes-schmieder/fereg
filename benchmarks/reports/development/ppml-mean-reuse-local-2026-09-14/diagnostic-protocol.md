# Mean-refresh attribution diagnostic

The four untraced screens are complete. Complete/FW clear the time-only gate,
but ordinary refresh savings are 6.104/2.189 ms while command savings are
349/83 ms. The narrow command saves 14 ms and misses 2%; PW misses 2% as well.
Do not treat unchanged finite-solve variation as a mean-cache gain. Before any
repeated performance campaign, instrument only the accepted-mean conditional in
separate baseline/candidate copies. Record every refresh call, compact row count,
reuse flag, elapsed mean construction and exact workspace/tag type size. Run the
original complete/FW/narrow full/warm requests, with exact scientific/solver
comparison against each original arm and across arms. Separate initial warm calls
by their row counts. Retain all captured calls, but do not combine instrumented
command times with the untraced timing screen. If the measured mean work is too
small to explain a qualifying command gain, reject this standalone prototype;
otherwise proceed with the repeats and controls required by the original protocol.
No data changes or generated data, builds/tests overlapping timing, agents,
cluster, upstream or R1–R5 work.
