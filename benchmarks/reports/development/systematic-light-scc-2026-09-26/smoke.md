## Corrected oracle defect

The original smoke had 25 passing native oracle checks. The bounded zero-count
oracle implemented only all-zero FE-group and singleton deletion, missing
separation through combinations of model columns. In sparse two/three-FE zero
cases it retained 950 observations; feppml retained 938 and 943. The stock
comparators also retained larger samples, so those pairs are incomparable.

ADR 0223 introduces an independent full explicit-model recession-cone LP and
sign certificates. After iterative separation, the exact SCC input replay
matches native retained observation hashes, coefficients, full covariance and
objective in **all four zero cases**. This supports all **27 successful native
fits** across the smoke. It does not turn the missing native fit into a pass.

An initial Mac reconstruction found the same samples and numerical agreement,
but its x3 value hash differed from SCC. That reconstruction was rejected as
exact-input evidence. The accepted adjudication regenerated byte-identical DTA
inputs on SCC, checks every original column hash and binds the captured native
result hashes. No estimator was rerun. `zero-oracle-adjudication.json` contains
accepted source identities, separation traces, sample hashes and full oracle
results. All **21 local controller tests** pass, including an analytic
finite-regressor separation/singleton case and an opposing-boundary no-separation
case. The corrected source is separate from the immutable original controller.
