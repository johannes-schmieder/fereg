PPML Auto with exactly two fixed effects now reuses one CMG preconditioner across IRLS iterations, in the joint FE solves and in the canonical products of the first iteration and the strict checkpoint. Publication fits enter the strict checkpoint only once the accepted predictor is predicted to settle within the strict envelope, so weakly connected designs pass their first checkpoint instead of repeating it at a 100-times tighter tolerance. Canonical products solve small graph components directly, and PPML iterations with fixed effects make fewer, parallel passes over the data.

On Linux with 4 and 28 workers, two-effect PPML designs with 2% worker mobility ran in about 0.32-0.38 of beta.6's time at one and four million rows; AKM and dense two-effect designs ran in 0.73-0.84. Results agree with beta.6 within the documented tolerances; sample, rank, omission and separation decisions are unchanged, and iteration counts can differ. OLS is unchanged bit for bit.

Linux x86-64, Windows x86-64 and universal macOS plugins are included; Stata 18 or newer is required and no compiler is needed to install the package. Native loading and installed OLS/PPML tests were run separately on each platform; native Intel-host Stata testing remains outstanding.

The release includes the binary package, flat files for `net install`, checksums, and matching corresponding source with pinned dependencies and licenses. See `docs/VALIDATION.md` for the evidence. GitHub Actions remain disabled.
