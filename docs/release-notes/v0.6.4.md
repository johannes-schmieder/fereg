fereg 0.6.4 improves Poisson separation checks, preserves explicitly chosen factor-variable base levels, and handles saturated fits with exactly zero clustered covariance. It recovers nearly collinear slopes in supported OLS and PPML models when the estimates and inference can be reported faithfully in the original units. It also speeds up wide OLS.

See the [changelog](https://github.com/johannes-schmieder/fereg/blob/v0.6.4/CHANGELOG.md).

Reopen Stata and run

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.6.4/") replace
fereg, selftest
```
