fereg 0.6.2 restores much of the Poisson performance lost in 0.6.1, especially for separated models and specifications with many redundant indicator columns. The numerical accuracy checks remain in place.

- `feppml` uses the same negative-eigenvalue repair as `ppmlhdfe` for multiway clustered covariance, including its standardization and intercept.
- `fereg` fixes a solver failure on weakly connected two-way fixed effects.
- A tighter rank check can switch solvers without rejecting a certified fit.
- See the [changelog](https://github.com/johannes-schmieder/fereg/blob/v0.6.2/CHANGELOG.md) for details.

Reopen Stata and run

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.6.2/") replace
fereg, selftest
```
