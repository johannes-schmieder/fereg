Beta.11 migrates the fixed-effect dependency to a small patch stack based on frozen upstream `py-econometrics/within` commit `32dde1bd`, pinned through Johannes's fork at `8d401d82`.

The migration preserves fereg's Auto routing and Jacobi-to-Schwarz escalation, explicit solvers, controlled warm starts and shared iteration budgets, weights, slopes, memory admission, cancellation and independent numerical validation. It includes the accepted counts, gather, Fold and sparse back-substitution improvements. Scatter specialization remains excluded.

Two large fitted-value disagreements with external references were investigated using independent optimality-error bounds. Both beta.10 and beta.11 pass the resulting checks on Mac and Linux without relaxing the existing tolerances. The original discrepancies and execution timeouts remain documented.

Performance is a reviewed tradeoff: the original Mac sparse-three-FE and Linux near-confounded-three-FE regressions are recovered, while the accepted eight-/sixteen-FE settings remain approximately 8–11% slower on Linux and 11–14% slower on Mac. Several settings remain inconclusive. This release makes no claim of universal non-regression.

Supplied platforms: Linux x86-64 (glibc 2.28 or newer), Windows x86-64, and universal macOS. Native Intel-Mac Stata testing remains outstanding. The source ZIP includes the exact locked dependencies, license texts and an offline Cargo configuration. The [validation report](https://github.com/johannes-schmieder/fereg/blob/main/docs/VALIDATION.md#beta11-migration-packaging) records the native, scientific and installation checks, their results and limitations.

Install the versioned package in Stata:

```stata
net install fereg, from("https://github.com/johannes-schmieder/fereg/releases/download/v0.5.0-beta.11") replace
fereg, selftest
```

For the current `main` package, use:

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/main/") replace
```

Both direct installation routes passed fresh-session checks. The community `github` helper downloaded the correct package but failed in its subsequent release-metadata query; use `net install` while that helper limitation remains unresolved. This does not change the native release assets.
