This Mac beta publishes the accepted OLS Auto-routing, CMG host-team, ownership and deferred-cell improvements. Existing explicit solver requests, scientific certificates, public memory controls and atomic rollback remain supported.

The universal plugin includes Apple Silicon and Intel slices. Licensed installation testing is on Apple Silicon with Stata 19; Stata 18 remains the minimum supported version. Native Intel-host Stata and Linux/Windows binary distribution are not qualified by this release.

Install this version in a fresh Stata session:

```stata
net install fereg, from("https://github.com/johannes-schmieder/fereg/releases/download/v0.5.0-beta.3/") replace
fereg, selftest
```

The binary ZIP contains the flat installation files. The source ZIP includes the exact dependency sources, licenses and offline configuration needed to rebuild the universal plugin. Follow the accompanying build instructions. Published beta.1 and beta.2 assets remain unchanged.

The completed Linux and practical Mac performance qualification is reused. This packaging pass adds actual universal binary audit/ABI/load/panic checks, source integration, independent installed OLS/PPML examples and public OLS Break/rollback. GitHub Actions remain paused.
