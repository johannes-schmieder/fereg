# fereg 0.5.0

The first stable 0.5.0 release promotes the qualified beta.15 runtime. The Linux, Windows and universal macOS native binaries are byte-for-byte identical to beta.15. Stable package metadata, help text, source links and the version returned by selftest and estimation now identify 0.5.0.

## Plugin loader repair — November 4, 2026

At the author's explicit request, main, the v0.5.0 tag and the binary,
corresponding-source and SSC archives now include the repair for
[issue #35](https://github.com/johannes-schmieder/fereg/issues/35), reported by
Mauricio Caceres Bravo. The loader resolves home-directory (`~/...`) and
relative paths before registering the plugin, preventing the reported `r(601)`.
The helper remains inside the existing loader file and preserves the working
directory and existing Mata variables. All native plugin binaries are unchanged.

The full source test suite passes. Mac Stata/MP 19 checks cover tilde paths,
spaces, parent traversal, reloads, transactions and independent OLS/PPML
witnesses. The refreshed packages are checked by installation, and the source
archive is verified with a fresh offline universal Mac build and native ABI
checks. No new Linux, Windows, native Intel-Mac or Stata 15 execution is claimed.
The corresponding-source packaging commit is
`2889939cec1297c332f5f1975b61eaa641f0871a`; prior tag and archive identities remain
in the [publication record](https://github.com/johannes-schmieder/fereg/blob/main/bench/results/v050-publication-20261103.json).
Restart Stata and reinstall with `replace` to obtain the repaired loader.

## Included commands

- **`fereg`**: OLS and weighted least squares with high-dimensional fixed effects, factor variables, absorbed slopes, supported weights, robust and clustered inference, saved fixed effects and predictions.
- **`feppml`**: Poisson pseudo-maximum likelihood with high-dimensional fixed effects, separation handling, supported weights and offsets, robust and clustered inference, and predictions.
- One Rust computational runtime, automatic and explicit supported solvers, public memory controls and numerical checks before results are published. No separate Rust, Python, Julia, BLAS or OpenMP installation is needed.

## Installation

Requires Stata 15 or newer. Exit Stata before updating, then start a fresh session and run:

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.5.0/") replace
fereg, selftest
help fereg
help feppml
```

The tag pins this release. The `main` installation URL and `github install johannes-schmieder/fereg` follow the current main package. For offline installation, extract `fereg-0.5.0.zip` and run `net install fereg` from the extracted directory.

## Validation and limitations

The unchanged native binaries retain the [beta.15 platform qualification](https://github.com/johannes-schmieder/fereg/blob/v0.5.0/bench/results/beta15-publication-20261102.json) and the completed [November 2–3 benchmark campaign](https://github.com/johannes-schmieder/fereg/blob/v0.5.0/bench/results/scc-20261102-beta15.md). The stable package adds a fresh dependency audit, source-archive offline build, binary/ABI checks and installed-package OLS/PPML checks. The source archive includes the exact locked dependency sources and license notices.

- **Linux x86-64:** glibc 2.28 or newer.
- **Windows x86-64:** numeric input remains serial pending live Break qualification.
- **macOS:** universal Apple Silicon/Intel plugin; licensed Stata testing uses Apple Silicon. Native Intel-Mac Stata testing remains outstanding.
- Performance depends on the model and hardware. Prior accepted regressions remain, including the 7.3% Linux one-worker, 16-regressor no-fixed-effect slowdown relative to beta.14. Comparator numerical discrepancies and timeouts remain visible in the benchmark evidence; this release does not claim universal speed superiority.
