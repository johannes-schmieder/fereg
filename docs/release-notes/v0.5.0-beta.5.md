Linux x86-64 and Windows x86-64 binaries are now included alongside the universal macOS plugin. Stata 18 or newer is required; no compiler is needed to install the package.

OLS results identify the method actually used: `cg`, `cmgschur`, or a MAP fallback. The current help and installation guide describe these results and the accepted Auto defaults.

Native audit/load checks and installed OLS/PPML tests were run separately on Linux, Windows, and Apple Silicon macOS. Native Intel-host Stata testing remains outstanding. Numerical calculations and solver selection are unchanged by this packaging update.

The release includes the binary package, flat files for `net install`, checksums, and matching corresponding source with pinned dependencies and licenses. GitHub Actions remain disabled.
