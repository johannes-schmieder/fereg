# fereg 0.6.8

This release improves Poisson separation detection on sparse models with many fixed effects, continuous controls, or absorbed slopes. The solver can verify separating directions directly on the original observations and can use a lower-memory method when its usual workspace would exceed the fit budget. Once separation finishes, the coefficient solver can reuse the available memory.

Some very large unit-specific trend models and models run just above their minimum memory requirement can still take a long time. The improvement has been verified on the reported extracts and synthetic panels.

The [tagged distribution](https://github.com/johannes-schmieder/fereg/archive/refs/tags/v0.6.8.zip) contains the Stata installation package. The [corresponding source archive](https://github.com/johannes-schmieder/fereg/releases/download/v0.6.8/fereg-0.6.8-source.zip) includes the pinned dependencies and their licenses.
