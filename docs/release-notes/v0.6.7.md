fereg 0.6.7 improves Poisson separation checks for models with many categorical controls, crossed fixed effects and varying slopes. A sparse search can use additional memory when the fit has room and continue while it is making progress. Before it removes observations, feppml verifies the proposed separation on the original rows.

The release includes native plugins for macOS, Linux and Windows. Reopen Stata and run

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.6.7/") replace
fereg, selftest
```

For offline use, the [tagged distribution](https://github.com/johannes-schmieder/fereg/archive/refs/tags/v0.6.7.zip) contains the installable package and all three plugins. The [corresponding source ZIP](https://github.com/johannes-schmieder/fereg/releases/download/v0.6.7/fereg-0.6.7-source.zip) includes the pinned dependencies and their licenses.

The [changelog](../../CHANGELOG.md) describes the changes. The tag contains the [checksums](v0.6.7-SHA256SUMS) and [offline Mac build instructions](../macos_source_build.md).
