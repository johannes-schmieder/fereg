fereg 0.6.3 fixes a weighted PPML crash with redundant categorical controls and speeds up separation checks. It also reduces repeated work in wide fixed-effect projections and QR calculations. The final fit and separation checks still certify the full model.

See the [changelog](https://github.com/johannes-schmieder/fereg/blob/v0.6.3/CHANGELOG.md).

Reopen Stata and run

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.6.3/") replace
fereg, selftest
```
