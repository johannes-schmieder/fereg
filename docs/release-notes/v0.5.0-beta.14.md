Beta.14 improves input transport and removes the serial FE loading cutoff above 64 total numeric input columns. Scientific results agree exactly with beta.13 at fixed worker counts in the qualification checks.

- Shared numeric loading uses Stata-resolved `in` bounds, preserves original row identities and missing-value bits, accounts for descriptor capacity, and preserves transient SDK errors. Parallel phases bound both row/slot work and total accounted work between Break checks while retaining the established scheduling geometry.
- Wide numeric FE inputs use tiles bounded by value count. The two tile buffers stay within 4 MiB; prepared categories and RHS storage are separately admitted against the memory limit. In the 100,003-row, four-worker Linux test, serial loading improves about 20–23% at 65/130 total input columns and whole estimation improves about 6–9%. Prepared storage can increase peak memory, and parallel loading is not uniformly faster.
- Successful OLS and PPML calls retire obsolete private sample variables together, preserving transaction rollback and the posted sample.

Performance is mixed, with explicit approval to publish the measured exceptions. The main comparison passes 28/28 Mac and 41/42 Linux settings; the remaining Linux no-FE case is 5.64% slower. The additional width-boundary comparison passes 40/40 Linux and 36/40 Mac settings. All changed FE settings pass; the four failed Mac no-FE controls are about 5.7–6.2% slower in the affected comparisons. Every observation is retained, and the original failures remain documented. This release does not claim a universal speedup. See [validation and reports](https://github.com/johannes-schmieder/fereg/blob/v0.5.0-beta.14/docs/VALIDATION.md).

Includes Linux x86-64 (glibc 2.28+), Windows x86-64, and universal macOS binaries. Windows retains serial input pending live Break qualification. Native Intel-Mac Stata testing and interactive GUI Break remain qualification gaps. Exact scientific replay, input oracles, transactions and live console Break passed on the applicable tested platforms.

The source archive includes locked dependencies, license texts, the dependency audit and offline build instructions. Each binary is bound to its actual build source and checksum. Restart Stata after updating so the matching ado files and plugin are loaded together.
