fereg's fixed-effect solvers now live in fedemean: exact elimination of the largest effect for two to five categorical effects (OLS Auto and PPML's categorical projections), conjugate gradients on the full system with Jacobi escalating to additive Schwarz, and the in-tree modified LSMR engine. The `within` dependency is removed, CMG is pinned to the published 0.3.0 release, and LSMR and the rank-revealing QR use a portable `hypot`, so their iterations and pivots no longer depend on the platform. Of exactly collinear regressors, the one listed first is kept on every platform.

**Breaking changes.** `solver(method[, reduce() precondition() accelerate()])` replaces the former `solver()` values, `preconditioner()` and `cmgdegree()`/`cmgsamples()`/`cmgseed()`; `feppml` accepts `auto`, `lsmr` and `cg` and no longer accepts `solver(map)`. Results report the route in `e(fe_route)`, `e(fe_method)`, `e(fe_preconditioner)` and related `e(fe_*)` names; `e(fe_requested)` replaces `e(fe_solver)`, `e(fe_solve)` replaces `e(fereg_solver)`/`e(feppml_solver)`, and `e(fe_local_solvers)` replaces `e(fe_block_solvers)`. There are no aliases. See `CHANGELOG.md`.

Estimates agree with 0.5.3 within the solver tolerance, most in the last digits; samples, ranks and separation decisions are unchanged.

Includes Linux x86-64, Windows x86-64 and universal macOS plugins, the locked corresponding-source closure, dependency audit, licenses and offline Mac build instructions. Native Intel-Mac execution remains unqualified. The accepted Windows loading Break limitation and historical performance exceptions remain; see `docs/VALIDATION.md`.

Install from the versioned catalog in a fresh Stata session:

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.6.0/") replace
fereg, selftest
```
