fereg 0.6.5 improves Poisson separation for sparse models with factor controls and fixed effects. It can reuse an independently checked simplex proof, recover from a stalled IR calculation, and complete difficult finite fits when the original-unit results pass numerical checks.

See the [changelog](https://github.com/johannes-schmieder/fereg/blob/v0.6.5/CHANGELOG.md).

Reopen Stata and run

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.6.5/") replace
fereg, selftest
```
