This macOS beta supplies `fereg` and `feppml` for Stata 18 or newer.

The universal plugin contains Apple Silicon and Intel code. Native ABI/load checks and licensed Stata installation, OLS, PPML and rollback checks pass on Apple Silicon with Stata/MP 19. Native Intel-host, Linux and Windows qualification is not established by this release. There is no new performance claim.

Install the current package from main:

```stata
github install johannes-schmieder/fereg
```

Or use `net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/main/") replace`. Restart Stata before updating.

The native build uses source commit `46aa78f67b102373675b7c72196dba1fbfb7d337`. The main-branch package binds the binary to runtime production tokens and native artifact inputs, permitting later documentation-only updates. The source ZIP contains exact dependency sources, licenses, build scripts and a relocatable offline Cargo configuration. An empty-cache offline build passes; the dependency audit reports zero vulnerabilities.
