Beta.12 changes the Stata interface only. The numerical code is that of beta.11, and estimates are identical: all 77 plugin replay cases match beta.11 exactly.

- **Stata 15 or newer** instead of Stata 18 or newer. The ado-files use Stata 15 syntax, the PPML Mata objects are compiled by Stata 15, and the plugin accepts Stata 15. The new replay fixture passed on Stata 15.1, 16.1, 17 and 18 on Linux and on Stata 15.1 and 18 on Mac; the full fixture profiles ran on Stata 19 on all three platforms and on Stata 18 on Mac.
- **Replay.** `fereg` and `feppml` without a variable list redisplay the last results with Stata's display options, so `estimates replay`, `bootstrap:` and `jackknife:` now work.
- **`e(fereg_version)`** records the release with every set of results; `fereg, selftest` returns `r(fereg_version)`.
- **Clearer output.** The line above the OLS coefficient table now reads, for example, `Fixed-effect solver: cg   Accuracy check: passed (tolerance 1e-08)`. Saving `d()`, `mu()`, residuals or effects no longer prints "missing values generated".
- **Clearer error.** When a loose `tolerance()` prevents certifying the OLS coefficients, the error names the tolerance and suggests a smaller one (still r(459)).

Supplied platforms: Linux x86-64 (glibc 2.28 or newer), Windows x86-64, and universal macOS. Native Intel-Mac Stata testing remains outstanding. The source ZIP includes the exact locked dependencies, license texts and an offline Cargo configuration. The [validation report](https://github.com/johannes-schmieder/fereg/blob/main/docs/VALIDATION.md#beta12-interface-packaging) records the native, scientific and installation checks.

Install the versioned package in Stata from its release tag:

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.5.0-beta.12/") replace
fereg, selftest
```

For the current `main` package, use either of:

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/main/") replace
github install johannes-schmieder/fereg
```

**Release files.** From this release on, releases carry only the binary and source ZIPs, their checksums and the Mac build notes; the per-file copies were removed from earlier releases too. The community `github` helper reads the whole release list as one Stata line, and those copies had made it longer than Stata's line limit, so `github install` failed with r(132). Every file remains in the binary ZIP, and each release tag from beta.2 on installs exactly the plugins released with it.
