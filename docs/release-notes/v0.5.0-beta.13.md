Beta.13 makes loading and PPML faster. OLS estimates are identical to beta.12 (all OLS plugin replay cases match exactly). PPML estimates with several fixed effects can differ in the last digits because the solver now starts from better values; every tolerance and accuracy check is unchanged.

- **Parallel loading.** Numeric variables are read from Stata in parallel on qualified installations: Stata 18 and 19 MP on Apple Silicon Macs and Stata 17, 18 and 19 MP on Linux, console and GUI. Loading a million rows takes a fraction of its former time (for example 0.31 s to 0.05 s for 64 regressors on eight workers), and whole commands are up to twice as fast. Other installations (including Windows and Stata SE/BE), alias variables and string variables keep the previous reader, and the loaded data are the same bit for bit.
- **Faster PPML.** PPML with several fixed effects starts each joint solve from the last certified fit and streams its coupling terms in one pass, which makes sparse three-FE PPML about a third faster. One-FE PPML is faster too, and explicit `solver(lsmr)` PPML reuses its core factor while weights change little.
- **Host scope.** `feppml` keeps Stata's processors from one million observations, where its own per-row passes cost more than running them serially.
- **Protocol 1.7.** The ado-files and plugin now use action protocol 1.7; install both together and restart Stata after updating.

Supplied platforms: Linux x86-64 (glibc 2.28 or newer), Windows x86-64, and universal macOS. Native Intel-Mac Stata testing remains outstanding. The source ZIP includes the exact locked dependencies, license texts and an offline Cargo configuration. The [validation report](https://github.com/johannes-schmieder/fereg/blob/main/docs/VALIDATION.md#beta13-parallel-input-and-parity-packaging) records the native, scientific and installation checks.

Install the versioned package in Stata from its release tag:

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.5.0-beta.13/") replace
fereg, selftest
```

For the current `main` package, use either of:

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/main/") replace
github install johannes-schmieder/fereg
```

Releases carry only the binary and source ZIPs, their checksums and the Mac build notes; every installed file is in the binary ZIP, and each release tag from beta.2 on installs exactly the plugins released with it.
