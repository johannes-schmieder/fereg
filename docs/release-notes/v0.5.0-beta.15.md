Faster parallel OLS without fixed effects, for Fast unweighted IID fits with an intercept, automatic solvers and no optional observation outputs. Stable centered products, packed-input reuse and a certified residual shortcut reduce native preparation and solve work. Independent original-data checks, rank rules and scientific tolerances remain intact.

At one million observations and 64 regressors, 16-worker command time fell from 3.101 to 0.709 seconds on the measured Linux host and from 1.157 to 0.316 seconds on Mac. These are descriptive results on one host per platform. Stata regress remains faster in many equal-processor comparisons; its licences were capped at four/eight processors on Linux/Mac.

Johannes explicitly accepted the Linux 16-regressor, one-worker slowdown of 7.3% versus beta.14 for this release. The failed guard and all observations remain in the [performance report](https://github.com/johannes-schmieder/fereg/blob/main/bench/results/no-fe-preparation-20261102.md). No timings were discarded or repeated.

Includes Linux x86-64, Windows x86-64 and universal macOS plugins with corresponding source, complete vendored dependency sources and licences. Windows retains serial Stata input. Native Intel-Mac Stata execution is not yet qualified. The Linux plugin requires glibc 2.28 or newer.

Update with `github install johannes-schmieder/fereg, replace`, or install this version from `https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.5.0-beta.15/`. Restart Stata after updating a loaded native plugin.
