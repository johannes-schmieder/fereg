OLS Auto with three or more categorical-intercept fixed effects now starts LSMR with a diagonal preconditioner and builds the additive Schwarz preconditioner only when the projected work is large. With three unit-weight effects, a short certified MAP pilot may finish first. Every route must pass the requested FE-moment certificate.

On Linux, designs with four, eight and sixteen effects and a small third effect ran in about 0.60-0.68 of beta.5's time across 12 physical hosts. One near-confounded three-effect design is about 6-13% slower; this is a documented exception. Two-effect, one-effect, slope, explicit-solver and PPML behavior is unchanged, and sample, rank and omission decisions are unchanged.

Linux x86-64, Windows x86-64 and universal macOS plugins are included; Stata 18 or newer is required and no compiler is needed to install the package. Native loading and installed OLS/PPML tests were run separately on each platform; native Intel-host Stata testing remains outstanding.

The release includes the binary package, flat files for `net install`, checksums, and matching corresponding source with pinned dependencies and licenses. See `docs/VALIDATION.md` for the evidence. GitHub Actions remain disabled.
