fereg 0.6.6 improves numerical recovery for linear regressions with robust or clustered standard errors, including specifications with redundant categorical controls or rare factor levels. It also reports when the multiway OLS covariance needed a negative-eigenvalue adjustment.

For all changes see the [changelog](../../CHANGELOG.md).

[SHA-256 checksums](v0.6.6-SHA256SUMS) and [offline Mac build instructions](../macos_source_build.md).

Reopen Stata and run

```stata
net install fereg, from("https://raw.githubusercontent.com/johannes-schmieder/fereg/v0.6.6/") replace
fereg, selftest
```
