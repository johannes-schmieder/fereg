## Executable evidence

[program-v1.json](../../bench/program-v1.json) runs through the existing
`bench/run.py`, generator and Stata capture, with the existing pinned reference
environment. `--source-root` selects the frozen source/frontend/binary snapshot;
`--paired-source-root` interleaves the parent/fixed artifact with the candidate;
`--reverse-order` inverts each pair as well as cell/thread/comparator ordering. Raw data and
captures stay in ignored run roots. Archive, binary, frontend, runner, compiler,
dataset and manifest hashes identify evidence. No timing or routing change is
claimed for M26.

The core cube crosses Mac 1/2/4/7/8/9/15/16 or SCC 1/2/4/8/14/28 with outputs
and VCE in eight intercept strata plus finite-factor and absorbed-slope strata.
PPML IID maps to robust; zero-FE saved effects
have no channel. Those exclusions and unsupported explicit requests are named.
Covering cells add modes, weights, width/row neighbors, weak/disconnected/skewed
graphs, slopes, separation and both bias modes. Existing grammar, rank, weak
graph, strict PPML, saved-FE and transaction fixtures remain independent science.
The holdout tier is reserved from tuning and combines frozen new shapes/seeds
with skewed weighted, disconnected factor and three-FE slope models.
Revealed holdouts require replacement before a generalization claim.

Command median is primary. Each artifact/cell gets one warmup and 32 fresh
processes per block, in alternating artifact pairs. Exactly one forward and
one inverse-order block are allowed. The resolution check uses the central 95%
paired percentile-bootstrap interval for the difference of command medians,
with 50,000 resamples and fixed PCG64 seed 260041. Protocol `monotonic-command-v1`
uses the isolated command stopwatch and enlarges the interval by 2 μs for
difference quantization. Each duration's 1 μs allowance bounds two counter
endpoints at the required resolution ≤500 ns. Dispatch/scheduling variability
remains measured; no overhead is subtracted. Stata's millisecond command timer
is retained as a secondary witness. Both upper bounds must fit the unchanged 5% or 1 ms allowance;
two lower bounds beyond it confirm failure. The existing comparator executable
requires both immediate-parent and fixed-baseline comparisons with matching
artifact/tooling/manifest/data identities and complete accurate ordered pairs.
Identical-artifact calibration and an independent inverse-order validation block
precede runtime candidate measurements. Each calibration interval must lie
inside the symmetric [-allowance,+allowance] bound, with identical source,
native and frontend identities. Post-timing identity verification is required.
All other outcomes remain unresolved. Noise exceeding the allowance
requires improved measurement before claiming acceptance; it cannot buy a
wider budget or be called equivalence through overlapping ranges. A neutral
extraction cannot substitute for M35's predeclared broad gains.

Predeclared expensive families are multi-FE PPML direction/strict/final work,
wide OLS finite algebra and saved-product/inference assembly, and SCC-scale
strong/weak graph models. M24 supplies independent repeated-work attribution.
The existing `suite.toml` external arms remain pinned contextual competitiveness
witnesses; the program's artifact pairs use the qualified next engine.

Preparation/encoding and publication boundaries come from host runtime timers
and owner capacities. FE setup/projection/recovery, finite solves and PPML
strict/final work use existing runtime/solver tables and untimed phase traces.
Inference/output buffer lifetimes come from the counted core/host owners and
allocation audits. Absent row-pass or observed-memory counters stay unavailable;
the M24 profiles identify repeated normalization independently of phase timers.
No synthetic zero is used for unavailable telemetry.
